# 项目总览
一个快速验证的项目, 验证是否有开源/快速的音频服务接口可以使用
目前关注到的是 Podcasts Apple, Apple iTunes Search API, Podcast Index API,
验证完成后要代码移植到 zephyr C 语言环境中, 由 esp32s3 设备运行

# 接口验证
重点验证以下接口的能力, 可以是API直接提供, 或者由自己聚合组合实现也可以, 但尽量不要假设中间服务器, 完全由端侧发起
- 获取专辑列表, 及专辑标签
- 获取专辑详情, 及专辑下的音频列表
- 获取音频详情, 及音频的播放地址
- 实时播放和下载音频
- 搜索, 按标签过滤专辑和音频
